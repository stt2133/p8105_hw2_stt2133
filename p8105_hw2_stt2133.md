to a logical variable (TRUE vs. FALSE). The dimension of the resulting
dataset was 1868 rows x 19 columns. At this point, the dataset is not
tidy. For example, each observation is not unique and has duplicates of
every corresponding value.

## Import, Clean, and Tidy Baseline Demographics Dataset

``` r
mci_baseline_df = 
  read_csv("data/MCI_baseline.csv",
           skip = 1,
           na = ".") |>
  janitor::clean_names() |>
  mutate(
    sex = case_match(sex,
```

The MCI_baseline.csv dataset was imported as mci_baseline_df. The first
row was skipped as it contained variable descriptions and coding schemes
for each corresponding column. Any value in the dataset that consisted
solely as a character string of a single period (“.”), was interpreted
as a missing value during the import step. Thereafter, column names were
converted to lower snake case. The values of the two binary variables
(sex and apoe4) were converted from numeric 1 vs. 0 values to more
appropriate and descriptive character strings (male/female and
carrier/non-carrier). A new column was added to denote the time (in
years) between age_at_onset and current_age. Using this new onset_time
variable, rows in which onset_time were negative, indicating that the
participant had already developed MCI at baseline, were dropped from the
resulting dataset. In total, 479 participants were recruited and, of
these, 386 particpants went on to develop MCI. The average age at
baseline was 65 years. 30% of the women in the study were APOE4
carriers.
